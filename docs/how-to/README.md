# How-to Guides

How-to guides are **task-oriented** — they show you how to accomplish specific goals in
Portefaix Infrastructure (e.g. deploy a Terraform stack, run an Ansible playbook, build a Packer image,
trigger a Spacelift plan/deploy). These guides assume you already know the basics.

## Available Guides

- [Bootstrap the AWS cloud provider](bootstrap-aws.md)

## What's a How-to Guide?

How-to guides solve a specific real-world problem. Unlike tutorials (which teach),
how-to guides assume you know what you want to do and just need the steps.
